# Osciloscopio-32Mhz-Arduino-LGT8F328
Desarrollo de un prototipo de osciloscopio portable con auto calibración de tensión y frecuencia de manera manual desde la interfaz.

Osciloscopio OLED
32 MHz internos
Firmware PMO-RP1 portado del Arduino Nano 16 MHz al LGT8F328P. Reloj HFRC 32 MHz, ADC 10 bit con Vref 1.024 V, watchdog anti-cuelgue, EEPROM emulada con update, I2C 400 kHz y timebase estable.
